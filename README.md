## Overview

SugarSprout is a university software engineering project that involved designing and developing an e-commerce platform for a dessert business using Shopify.

The project focused on delivering a modern online shopping experience while following Agile software development practices, including sprint planning, backlog management, project documentation, testing, and deployment.

> **Note**
>
> This repository is a **case study** documenting the project's design, implementation, and software engineering process.
>
> The original Shopify store and source code are no longer available because the hosting subscription has expired.

---
